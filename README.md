# Social Media API

REST API built with Django and Django REST Framework (DRF) for a social media platform.

## Features
- **Authentication:** Secure JWT-based authentication using `djangorestframework-simplejwt`.
- **User Management:** Registration, profiles, and follow/unfollow system.
- **Posts & Comments:** Full CRUD operations for posts, and a commenting system.
- **Interactions:** Like toggle mechanism.
- **Personalized Feed:** View posts exclusively from followed users with built-in pagination.
- **API Documentation:** Interactive OpenAPI documentation via `drf-spectacular` (`/api/docs/`).

## Tech Stack
- Python, Django, Django REST Framework
- PostgreSQL
- SimpleJWT, Drf-Spectacular
